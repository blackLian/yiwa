# PRD：桌面 3D 猫宠 Companion

## 1. 文档目标

本文档用于统一产品、设计、客户端开发和 3D 资产团队的交付标准，覆盖 MVP 到 V1 的需求定义、验收标准与风险边界。

## 2. 产品目标

- 在 Windows 桌面常驻展示高质量 3D 猫咪（可爱 / 高冷双人格）。
- 建立鼠标、点击、桌面图标碰撞等交互反馈闭环。
- 以 3DGS 资产为核心，采用“多姿势切换 + 微位移”实现低复杂度高观感动画。
- 为后续 AI 对话和记忆系统预留稳定事件接口。

## 3. 用户故事

1. 作为用户，我希望猫咪常驻桌面但不影响工作视图。
2. 作为用户，我希望点击猫咪时有明显且符合性格设定的反馈。
3. 作为用户，我希望猫咪在图标附近有好奇行为，但不真正移动系统图标。
4. 作为用户，我希望一键切换“点击穿透”模式，避免遮挡操作。
5. 作为用户，我希望可爱猫和高冷猫行为明显不同。

## 4. 需求范围

### 4.1 功能需求（MVP）

- FR-01：透明置顶桌面窗口。
- FR-02：点击穿透开关。
- FR-03：双角色切换（可爱 / 高冷）。
- FR-04：每个角色至少 3 个姿势资产。
- FR-05：行为状态机（闲逛/停留/睡觉/回避/好奇/点击反应）。
- FR-06：鼠标接近事件响应。
- FR-07：图标碰撞视觉反馈（弹跳 + 气泡文案）。
- FR-08：点击响应与连续点击响应。
- FR-09：配置化人格参数。
- FR-10：录入与重建 Pipeline 文档化（拍摄、抽帧、重建、QC、导出）。

### 4.2 非功能需求

- NFR-01：交互延迟目标 < 120ms。
- NFR-02：行为切换必须无明显卡顿（状态切换帧丢失 < 1%）。
- NFR-03：配置文件加载失败时必须优雅降级到默认角色。
- NFR-04：只做视觉碰撞，不修改真实桌面文件或图标位置。

### 4.3 未来版本（不纳入当前实现）

- AI 对话、记忆与情绪系统。
- 云端资产同步。
- 多宠物同屏协作行为。

## 5. 验收标准（MVP）

- AC-01：可见透明窗口且支持置顶与取消置顶。
- AC-02：点击穿透开关生效。
- AC-03：可爱猫在鼠标接近场景下，50%+ 概率靠近或停留。
- AC-04：高冷猫在鼠标接近场景下，50%+ 概率回避。
- AC-05：图标碰撞时出现反馈文案，且图标实体不被移动。
- AC-06：空闲超阈值进入睡眠状态。
- AC-07：配置文件缺失字段时，系统返回可解释错误。

## 6. 风险与约束

- 3DGS 资产质量高度依赖拍摄质量。
- Windows 桌面透明窗与输入穿透在不同显卡驱动下可能存在兼容问题。
- 初期采用“姿势切换动画”可控性高，但真实骨骼动画表现有限。
